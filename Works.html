Studi Komparatif Efisiensi Memori antara Struktur Data Array dan Linked List

Jejak Digital: Jurnal Ilmiah Multidisiplin, Vol. 2 No. 4, 2026

Artikel ini membandingkan array dan linked list dari sisi efisiensi memori dan kecepatan operasi, lewat benchmark di C++ dan Python. Hasilnya, array unggul untuk akses data dan hemat memori, sedangkan linked list unggul untuk penyisipan dan penghapusan data di tengah, meski dengan overhead pointer yang besar.
